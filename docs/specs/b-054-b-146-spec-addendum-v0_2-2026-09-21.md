## 2. 確定事項（追加）

| # | 事項 | 出典 |
|---|---|---|
| D-27 | ★**数量の出し分け**。宛先 WO が **量産（PRODUCTION）** のとき: SKU の色×サイズ表（productionQuantity・カルテと同じ器）＋「この発注 N 枚」（WO 明細の quantity の合計）。**サンプル・追加・やり直し** のとき: 「この発注 N 枚」だけ（色×サイズ表は出さない）。★**量産の縫製工場は1品番1社**（分けない）ので、量産で SKU の表をそのまま載せてよい。表の合計と N が食い違うのは入力漏れのサイン | §1 原文 |
| D-28 | ★**区分の札**: PRODUCTION＝「量産」／SAMPLE＝「サンプル {sampleRound}」（値をそのまま出す。空なら「サンプル」）／ADDITIONAL＝「量産（追加）」／REWORK＝「量産（やり直し）」（D-16）。★「1次」への変換はしない（モック v8 の文言は「サンプル 2nd」） | モック v8・D-15・D-16 |
| D-29 | ★**付属の表は BOM の全行を itemOrder 順**に出す（生地も含む。モック v8 の1行目は「表地」・2行目は「リブ」）。列の当て方: 部位＝素材名（materialId があれば Material.materialName、無ければ customMaterialName）／品番＝supplierItemCode／仕様＝specification／色ごと＝BomItemColorway の supplierColorCode（supplierColorName があれば併記）・色別の行が無ければ5列を結合して「全色共通」（BomItem.colorCode があれば併記）／用尺/数＝usagePerUnit＋unit／手配＝仕入先名。空欄は「—」 | モック v8 の文言・§0 の5 |
| D-30 | 付属が15行を超えたら、15行まで出して表の下に「※ほか n 行（BOM を参照）」。D-6（10〜15品番）により通常は起きない | Claude 既定（変更可） |
| D-31 | ★**型紙の表示は「YYYY-MM-DD 種別」**（receivedAt＋PATTERN_WORK_TYPE_LABELS）。モック v8 の「修正（2nd）」の「（2nd）」は出どころが無いため**出さない**（モックからの逸脱として記録） | §0・ルール 2r |
| D-32 | パターンNO と先方品番が空なら「—」（D-20 と揃える）。型紙の行が無ければ型紙の欄も「—」 | Claude 既定 |
| D-33 | ページ番号は「n / 出力した総ページ数」（3枚目が複数枚になる場合も通し番号） | Claude 既定 |
| D-34 | ★**宛先 WO の条件**（ルートで検証）: 同じ companyId・deletedAt が null・**productId がその品番**。種類は 1枚目＝workType が SEWING（4a）。2枚目＝SEWING または INSPECTION、3枚目＝PRINTING / EMBROIDERY / WASHING / DYEING / FINISHING（4b で確定） | D-21・§0 の4 |
| D-35 | ★**クエリの形は 4a で3枚分すべて決め、4b・4c で変えない**。`?page=sewing:<woId>[:<sortOrder>]` を出したい順に繰り返す（種類は sewing / measure / process）。末尾の数字は載せる絵型の sortOrder（複数ならカンマ区切り・先頭が大きい絵型）で、省略時は sortOrder が最小の絵型。4a は sewing だけを受け付け、measure / process は 400 を返す | 4a/4b/4c の割り方 |
