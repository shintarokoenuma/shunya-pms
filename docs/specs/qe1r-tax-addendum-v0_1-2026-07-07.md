## 1. PDF 合計部の構成（v0.2 §3 の【総合計】を置換）
- 製品合計 → 初期費用合計 → 小計（税抜）→ 消費税（10%）→ 御見積金額（税込）の順。
- 小計（税抜）＝旧「総合計」（製品合計＋初期費用合計）。
- 消費税 ＝ 小計（税抜）× 10% を円未満切り捨て（Math.floor・消費税の一般慣行。
  単価の切り上げ規則とは別）。
- 御見積金額（税込）＝ 小計（税抜）＋ 消費税。強調表示は税込額に移す。

## 2. 税抜の明示
- 製品表の単価列ヘッダ「1枚単価（税抜）」・金額列「金額（税抜）」。
  初期費用表の金額列「金額（税抜）」。
- 入力フォームの手打ち欄ラベルに「税抜」を付記（1枚単価・初期費用提示額）。
  フォームの導出総額表示にも「（税抜）」を付記。手打ち値の意味は税抜で不変。

## 3. 実装方針
- 税率は表示層の定数 TAX_RATE = 0.10（quotation-data.ts）。スキーマ変更なし・保存しない
  （migration は 20260706000000 の1本のまま）。軽減税率は対象外。税率変更時は定数1箇所。
- QuotationPdfData に subtotalExTaxJpy / taxJpy / totalIncTaxJpy を追加
  （grandTotalJpy は subtotalExTaxJpy に改名可・原価/利益率非搭載の型方針は不変）。
