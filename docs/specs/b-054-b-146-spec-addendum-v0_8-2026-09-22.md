## D-74 3枚目の詳細図は「必要なときに追加」する形にする（確定）

- 背景: dev の確認で、3枚目に縫製 WO が全件「（詳細図）」として並び、見づらいことが分かった。WO が増えると悪化する。
  - 慎太郎さんの判断:「全部出すより使いで増やせたらいいな」
- 加工 WO（PRINTING / EMBROIDERY / WASHING / DYEING / FINISHING）
  - 行は今までどおり全件出す。既定でチェックが入る。
  - チェックを外した行は1行に畳み、サムネを隠す。チェックを戻すとサムネが出る。選んでいた画像は保持する。
- 縫製 WO（SEWING＝詳細図）
  - 最初は一覧に並べない。
  - 「＋ 詳細図を追加」のプルダウンで1件ずつ追加する。
    - 1枚目・2枚目と同じ、区分の見出し付きのプルダウン。
    - 「取消の作業発注も表示」の切り替えもそのまま効かせる。
    - 追加済みの WO は候補から外す。
  - 追加したものはカードで出す。
    - チェック済みの状態で、画像の既定は sortOrder が最小のもの1枚。
    - [×] で外せる。
  - 縫製 WO が1件も無いときは、追加のプルダウンを出さない。
- PDF に出す順: 3枚目は、加工 WO（一覧の順）→ 詳細図（追加した順）。
- 変更はダイアログの見た目だけ。
  - API / PDF の紙面 / 宛先条件（D-71）は変えない。
- 確認で OK: D-73 の区分見出し（1枚目・2枚目のプルダウン）。
