## 2. 画面（★文言はこの語のまま入れる）

### 2-1. 請求 一覧 /invoices

- nav「取引」の**納品の下**に `請求` を足す
- ボタン: `＋ 新規作成`
- フィルタ: `状態: すべて` / `クライアント: すべて`
- 表の列（この順・この見出し）:
  `請求書番号` / `クライアント` / `期間` / `繰越金額` / `今回御請求額` / `支払期日` / `状態`
- 状態の表示は3つだけ: `ドラフト` / `送付済み` / `取消`
- ★**繰越金額が 0 でない行だけ色を付ける**。0 は通常表示
- ★**今回御請求額がマイナスの行は赤系**で出す（赤伝だけの請求書・D-26）
- ★**並べ替え（未収のあるクライアントを上にまとめる等）は作らない**（D-37）
- ★**「未入金・一部入金・入金済み」のフィルタは作らない**（D-25・D-30）

参考画面の例（この3行が、それぞれ何を表しているか）:

| 例 | 表している設計判断 |
|---|---|
| INV-2026-0003 / 葵アパレル / 繰越 0 / 648,402 / 送付済み | 通常の月次 |
| INV-2026-0002 / スタイルバンク東京 / **繰越 1,918,400（色付き）** / 1,918,400 / 送付済み | **当月の納品が0でも繰越があれば請求書を出す**（D-24・KKAP+ 2026/08 の実例） |
| INV-2026-0001 / なんば商店 / 繰越 0 / **−33,000** / ドラフト | **赤伝だけの請求書で今回御請求額がマイナス**（D-26） |

### 2-2. 新規作成 /invoices/new

- 入力（上段）: `クライアント *` / `期間（締め日から自動・直せる）`
- 注記: 月末締め（締め日 31）なら 9/1〜9/30、20日締めなら 8/21〜9/20 が既定
- 見出し: `候補の明細（N件）`
- 候補表の列（この順・この見出し）:
  （チェックボックス） / `納品書` / `納品日` / `品番 / 品名` / `色・サイズ` / `数量` / `単価` / `金額`
  - 既定は**全部チェック済み**。外したい行だけチェックを外す
  - 赤伝の行（数量マイナス）は**赤系の背景**で出す
  - 非課税の行は税区分の tag（`非課税`）を付ける
- 注記（この文言）: `取消されていない請求書に既に載っている明細は候補に出ません`（二重請求の防止）。保存時にサーバでも再確認する
- 右カラム 見出し `金額`
  - `前回御請求額（このクライアントの最初の請求書だけ入力）` の入力欄
  - 注記: 2枚目からは直前の請求書の「今回御請求額」が自動で入り、**読み取り専用**になる。KKAP+ から移るときは最初の1枚だけ人が入れる（B-215）
  - 金額の並びは 2-3 と同じ8行
  - 注記: `消費税は請求書1枚につき税率ごとに1回だけ計算します`（D-22）。四捨五入なら 58,845.6 → **58,846**、切り捨ての取引先なら **58,845** で1円変わる（D-23・D-36）
- ボタン: `保存（ドラフト）` / `戻る`

### 2-3. 詳細 /invoices/[id]

- ヘッダ: 請求書番号（等幅・大）＋状態の tag、下に `クライアント名　期間　支払期日`
- ボタン: `取消` / `再発行`
  ★**`PDF` ボタンは参考画面に描いてあるが PR-2c では作らない。PR-4（請求書 PDF）のスコープ**
- 明細表の列（この順・この見出し）:
  `納品日` / `品番 / 品名` / `色・サイズ` / `税区分` / `数量` / `単価` / `金額`
  - 見せ方は案A（1 SKU ＝ 1行・D-19）
  - 赤伝の行は赤系の背景、金額はマイナス表記
- 左下 見出し `御入金（この期間）`
  - 表の列: `入金日` / `方法` / `摘要` / `金額`
  - 注記: 前回の締め日の翌日〜今回の締め日に記録された入金が入る
  - ★**入金は明細（InvoiceItem）にしない。別の節に入金日順で並べる**（D-33）
- 右下 金額（この順・この語・8行）:

      前回御請求額
      御入金額
      繰越金額            ← ここまでで1本の罫線
      10.0%対象
      非課税
      当月お買上げ額      ← ここまでで1本の罫線
      消費税等
      今回御請求額        ← 太字・上に二重線

  - ★`10.0%対象` と `非課税` は**税区分ごとに分けて出す**（D-32）。KKAP+ の癖（非課税を 10% 欄に含め税額だけ除く）は再現しない
  - ★8%（`REDUCED_8`）の行は、その税区分の明細があるときだけ出す
- 注記（この文言）: `送付済みにしたら書き換えません。` 誤りは 取消 → 新しい番号で再発行し、再発行側に元の請求書への参照を持つ（修正インボイス）。取消すと載っていた明細は候補に戻る

### 2-4. 入金（クライアント詳細の中の節）

- 置き場所は**クライアントの詳細画面**（請求書の詳細ではない・D-25）
- 見出し: `入金` ／ ボタン: `入金を記録`
- 補足文（この文言）: `入金はクライアントごとに記録します。次の合計請求書の「御入金額」と「繰越金額」に自動で入ります。`
- 一覧の列: `入金番号` / `入金日` / `方法` / `摘要` / `金額`
- 入力フォームの項目は**4つだけ**: `入金日 *` / `金額 *` / `方法` / `摘要`
- ボタン: `記録する` / `やめる`
- 注記（この文言）: `入れるのはこの4つだけです。内部では予定日＝入金日、状態＝着金確認済みで保存します（実績の記録なので予定と実績が同じ）。請求書への紐付けはしません。`
- ★`/payments` の独立した一覧も nav 項目も v1 では作らない
