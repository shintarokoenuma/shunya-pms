# 概算量産見積（QE-1R）仕様 addendum v0.2 (2026-07-06) — 手打ちレイヤーの転換

- 種別: spec addendum（quotation-rough-estimate-spec-confirmation-v0_1-2026-07-01.md への追補）
- 対象: v0.1 §5-2（手打ちレイヤー）・§5-3（保存の作法）
- 経緯: 見積書PDF の実物照合（2026-07-06）で「総額手打ち」が実務と不一致と判明。
  実務は「1枚単価を手で整え、総額は単価×数量で電卓が合う」形。
  詳細設計は quotation-pdf-and-list-spec-confirmation-v0_2-2026-07-06.md（道A）。

## 1. §5-2 の転換: 手打ちの単位は「総額」ではなく「1枚単価＋初期費用項目」
- 旧: 最終的な提示見積金額（総額）を人が手打ちで整える。
- 新: 人が手打ちするのは (a) 量産の1枚単価（finalUnitPriceManualJpy）と
  (b) 初期費用の各項目の提示額（RoughEstimateItem.presentedPriceManualJpy・INITIAL_COST 行のみ）。
  総額はすべて導出値（製品金額＝単価×MOQ・総合計＝製品合計＋初期費用合計）。
- 自動計算がデフォルト値として入り上書きできる、という v0.1 §5 の作法自体は不変。
  変わるのは「手打ちの粒度」のみ。

## 2. §5-3 の維持と適用先の変更
- 「自動値と手打ち最終値を別列で両方保存・手打ちで自動値を潰さない」は不変。
- 適用先: 自動参考単価は保存せず都度導出（calc.ts）。手打ちは新2列に保存。
  finalPriceManualJpy（総額手打ち）は非推奨化（列は残す・UI から撤去・読み書きしない）。
- INCLUDED の位置づけ: 「初期費用÷MOQ を単価に足した自動参考値」に降格。最終は手打ちが正。

## 3. 変わらないもの（確認）
- §6 絶対防衛線（初期費用を1枚原価に混ぜない）・§4 source（スナップショット焼き込み）・
  §7 通貨・§8 論点2〜5・利益率1件1率（Brand.defaultMarginRate 既定）はすべて不変。
