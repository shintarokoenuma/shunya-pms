| D-37 | ★**付属の表は案B**。①付属の表（部位・品番・仕様・色・用尺/数・手配の6列）②その下に「色ごとの指定」（色が変わる付属だけ。列＝カラーウェイ・最大5）。付属の表の色の欄は「全色共通」（BomItem.colorCode があれば「全色共通（100）」）か「色別（下表）」だけを出す。★モック v8 と v1.0 の「付属（色ごと）」＝色を列に並べる形からの変更 | §1「確かにBの方がわかりやすい」 |

## 3. 未決・申し送り

- 折り返しや「…」の位置に「-」が入る（fonts.ts の registerHyphenationCallback が1文字ごとを分綴点にしている）。発注書・見積書と共通。フォントの件と一緒に別番号で受けるか、この PR で縫製仕様書だけ止めるかは PDF を見て決める
- 現行 Excel にあって PDF に無い項目（気付・ブランド・品名・型紙枚数・芯使用箇所・部位ごとの縫製注意点）は未決
- 2枚目（採寸用・4b）のサイズ表は、Excel の「1st/2nd・サイズごとの指示寸と検寸・ピッチ」と v1.0 D-8（縫い上がり寸・加工後の2列）を突き合わせてから決める
