## 3. 設計のたたき台

### 3-1. 器（新しいテーブル2つ・非破壊の ADD TABLE）
- **受け取った請求書（ヘッダ）**: 相手先（種別 SUPPLIER / FACTORY / CONTRACTOR / OTHER＋id は任意＋読み取ったままの社名）・書類種別・書類No・発行日・締め日（＝月度）・支払期日・税抜・消費税・税込（Decimal）・通貨・読み取った登録番号・適格かどうか・状態・取り込み元（B-070 / 手入力）・原本スキャンの保存先・取り込みの束（月）・メモ
- **明細**: 投入先（読み取ったままの文字）・品番（productId・任意）・当て方の状態（自動で一致／人が確定／未一致／品番なし＝諸経費）・品番/品名/数量/単位/単価/金額税抜/税区分/摘要・発注（poId / woId・任意・後の段で使う）
- Invoice に「向き」の列を足して共用する案は採らない見込み（請求の画面・PDF・繰越・入金の集計がすべて clientId 前提のため）→ Q-6

### 3-2. 取り込み
- B-070 が月ごとに **shunya-pms 用の CSV（明細1行＝1行）** を出し、shunya-pms の画面からアップロードする（papaparse を使う）。B-070 のスキルの「PMSリンク（将来）」に沿う → Q-2
- 取り込みの前に確認の画面: 社名 → 仕入先・工場マスターへの当て（名寄せ）／投入先 → 品番への当て／B-070 の要確認の行／合計の検算。人が確定してから保存
- 同じ月を二度取り込んだときは、同じ（相手先・書類No・月度）を重複として止める
- 原本 PDF のアップロードは v1 では任意（原本ファイル名と頁は CSV から保存する）

### 3-3. 品番への当て
- 自動: 投入先を正規化（全角半角・大小・空白・ハイフン）して、先方品番 → 社内品番 → パターンナンバー（型紙番号）の順に完全一致を探す（D-1）
- 当たらない行は「未一致」として残し、画面で人が品番を選ぶ（未一致のまま保存も許す・後から当てられる）
- 品番に当たらない費用（運送・検査・倉庫保管料など）は「品番なし」として残し、費目（CostCategory）を付けられる → Q-8
- 人が当てた対応（投入先の文字 → 品番）を覚えて次の月に使うか → Q-5

### 3-4. 見せ方（v1）
- 一覧: 月・相手先・状態で絞る。相手先ごとの合計・品番ごとの合計
- 品番カルテ: 「仕入（請求書ベース）」の合計と明細（実際に払った額）。量産実績原価（B-201 のコスト）の材料になる
- 原本スキャンを1クリックで開ける

### 3-5. 後の段（v1 の後）
- 支払予定（Payment OUTGOING・SCHEDULED）を支払期日から作る＋期日の知らせ（Part3 §5.5）
- 発注（PO / WO）との照合: 発注漏れ・二重請求・金額の相違の一覧 → 承認 → 反映（M-039）
- 締め（月度で SUPPLIER / FACTORY のロック）

### 確定

- **D-1（Q-1）投入先は製品ナンバーかパターンナンバー。** 慎太郎さん（2026-10-08 21:15）原文「パターンナンバーと製品ナンバーが混在してます。初期に製品ナンバー無しで、進行した際にパターンナンバーを製品ナンバーとしてサンプルまで作成することがある。」

  - 自動の当ては §3-3 の順を **先方品番 → 社内品番 → パターンナンバー** に改める。パターンナンバーで当たり、その型番の品番が1つならその品番に、複数なら候補を出して人が選ぶ
  - ★ブランド・シーズン名だけの投入先（例「T.T MENS 27AW」「(後藤様)」）は品番に当たらない。未一致として人が当てるか、品番なしで残す

- **D-2（Q-2）取り込みは B-070 に shunya-pms 用の CSV を足す。** 慎太郎さん（2026-10-08）「B-070 に CSV を足す」を選択。B-070 の月次の成果物に「明細1行＝1行」の CSV を加え、shunya-pms はその CSV だけを読む（会社別明細の Excel は読まない）。列は §3-6。B-070 のスキル（shunya-invoice-monthly）の成果物の節に足す（別プロジェクト側の作業）
- **D-3（Q-3）仕入は締め日の月で数える。** 慎太郎さん（2026-10-08）「締め日の月」を選択（例: 8/31 締め・9/4 発行・9/8 着 → 8月分）。B-070 の「月度は締め日基準」と同じ。締め日が書かれていない単票は発行日（伝票日付）の月
- **D-4（Q-4・v1.1 で訂正）B-070 が「明細参照（計上しない）」にした行も取り込むが、計上しない。** 慎太郎さん（2026-10-08 22:30）「入れるが計上しない」を選択（21:30 の「入れない」は押し間違いとの申し出で聞き直した）

  - 一括請求書の行に品番が無いときに単票の投入先を写す作業（v1.0 の申し送り）は不要になる。品番は参照の行から見る
