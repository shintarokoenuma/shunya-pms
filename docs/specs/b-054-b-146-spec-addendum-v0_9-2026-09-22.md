## D-75 3枚目は「足したカード＝1ページ」に統一する（確定・D-74 を置き換える）

- 背景
  - 加工が2箇所以上に分かれることがある（例: プリント工場と洗い工場）。
  - 追加発注ややり直しで加工 WO が増えると、全件を並べる形（D-74）では一覧が長くなる。
  - 慎太郎さんの指摘:「加工ページも増やせてた方がいい」。
- 3枚目は、追加したカードだけを出す。カード1枚が1ページになる。
  - チェックボックスは使わない。[×] で外す。
  - カードごとに画像を4つまで選べる。既定は sortOrder が最小の1枚。
- 「＋ ページを追加」の Select
  - 候補は加工 WO（PRINTING / EMBROIDERY / WASHING / DYEING / FINISHING）と、縫製 WO（SEWING＝詳細図）の両方。
  - SelectGroup / SelectLabel で区分の見出しを付け、CATEGORY_ORDER の順に並べる。区分の中は加工 → 縫製の順。
  - 縫製 WO はラベルの末尾に「（詳細図）」を付ける。
  - 取消の表示切り替え（showCancelled）に従う。
  - 追加済みの WO は候補から外す（同じ WO を2ページにはしない）。
  - 候補が0件なら Select を出さない。
- 既定
  - 表示中の加工 WO から、pickDefaultWo と同じ規則（量産を優先し、その中で新しいもの）で1件だけカードを入れる。
  - 加工 WO が無い品番では空にする。
- 取消の表示を OFF にしてカードの WO が見えなくなったら、そのカードを外す。
  - 外す処理は切り替えのハンドラの中で行う（useEffect は使わない）。
- PDF のページ順は、カードを足した順。
- 変わるのはダイアログの見た目だけ。API / 紙面 / 宛先条件（D-71）は変えない。
- dev で「Cannot read properties of undefined (reading 'some')」が出た件（state.details）もあわせて確認する。
  - state を新しく作る箇所すべてで、新しい形がそろっていることを確かめる。
