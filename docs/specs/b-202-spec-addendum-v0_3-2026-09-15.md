## 3. ずれが生じた経路（2段階）

1. **書き起こし時（2026-09-12〜13）** — モックの「ボタン列＋共有パネル1枚」を `D-2「下開きの引き出し」` と要約した。誤りではないが **「パネルは1枚」という最も効いている性質が落ちた**。さらに v1.0 §4 Q5 の選択肢を「下開き／右パネル／別ページ」と立てたため、**モックに実在したタブ状のバーが選択肢から消えた**。1画面の3カラムは記録すらされなかった。
2. **実装時（2026-09-15 / PR-1）** — 落ちた書き起こしどおりに実装した結果、10 個の Collapsible が縦に並び、1画面も縦1列になった。実装は仕様書に忠実であり、**責任は書き起こし側にある**。

★ 「案B（タブ）を採用したのでは」という解釈は誤り。案B 不採用は正しい。**案C 自身が内部に持っていたタブ状UIと3カラムを、書き起こしで落とした**のが実態。

## 4. 訂正する決定

- **D-2r（D-2 を差し替え）** — BOM・見積・原価・伝票・書類は、1画面の下に置いた **横1列のボタンバー** から開く。開いた中身は **バーの下の共有パネル1枚** に表示し、同時に開けるのは1つ。パネルには見出しと「閉じる」を置く。
- **Q5r（addendum v0.1 Q5 を差し替え）** — 詳細の見せ方は「下開き（各セクションが自分の位置で開く）」ではなく **「共有パネル1枚の差し替え」**。中身は内側でスクロール。
- **D-12（新規）** — 1画面は **3カラムグリッド**（左=絵型 216px 固定 / 中=品番・分類＋縫製指示 / 右=SKU数量＋進行＋メモ）。狭幅では1カラムに畳む。
- **D-13（新規）** — ボタンバーの区分は **6グループ**。`資材表(BOM)` / `見積・原価（概算量産見積・量産見積・量産原価）` / `受注・発注` / `関連書類` / `マーキング実測・資材所要量` / `サンプル製作ラウンド・メタ情報`。
- **D-14（新規・保留を解消）** — 「基本情報」に独立ブロックは持たせない。クライアント・状態はヘッダ、工場は「品番・分類」に統合する。
- **Q6r（未確定）** — 担当者の置き場。案C に表示が無い。ヘッダ右端に足すか、非表示のままにするか要判断。
- **Q7（未確定・B-202 対象外の可能性）** — ヘッダの `付属手配 遅延2日` バッジ。進行データからの導出表示であり、B-096/B-101 の領域と重なる。今回は対象外とする。
