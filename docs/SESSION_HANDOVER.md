## 13. 注意点・残課題・教訓

1. ★**本番で請求書を作り始める前に、ERA とプレステージを切り捨てに直す**（B-215）。直さないと1円ズレた請求書が出る
2. ★**`NOT NULL` の `ADD COLUMN` はマージ前に本番の件数を測る。** `start` が `migrate deploy && next start` なので、失敗するとコンテナが起動せず**本番が落ちる**
3. ★**schema に列を足したら dev サーバを再起動する。** `generate` しても起動中の `next dev` は古い Client を掴んだままで、Prisma の Unknown field エラーが画面に出る。実装の不具合と読まない
4. ★**グリッドの子は `min-width: auto` なので `overflow-x-auto` が効かない。** 表を含むグリッド列には `min-w-0` を付ける。これが無いと表の最小幅がページ全体を横に伸ばす
5. ★**接続文字列の確認で `tail -c` の桁数を増やさない。** 40 にして本番パスワードの末尾3文字が画面に出た。host を見るなら `sed -E 's#^.*@##'`
6. ★**クリップボード方式は「ブロックを貼り付けてから Railway でコピーして Enter」の順。** 先にコピーしても指示ブロックで上書きされる
7. 納品書 `DLV-2026-0008` / `0009` は1円差の確認用に作ったダミー（単価 935・数量 3）。消してよい
8. Claude Code の commit trailer が `Claude Fable 5.1` になっている。履歴の書き換えはしない
