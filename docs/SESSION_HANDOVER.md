## 12. 注意点・残課題・教訓

- ★**open PR の上に次の PR を積まない。** 積んだ枝は、前の PR の squash マージ後に元 commit が残って差分が混ざる（今朝の #150）。`git rebase --onto main <前の PR の最終 commit>` ＋ force-with-lease で解消できる。
- ★**squash 済みの判定は SHA ではなく main の現物を git grep。** `git grep -c <語> origin/main -- <file>` の出力は `origin/main:<path>:<件数>` の3フィールドなので、件数は `awk -F: '{print $NF}'` で取る（今日 `cut -d: -f2` で誤 STOP した・指示側の誤り）。
- ★**無認証 curl は 401 ではなく 307**（src/proxy.ts が /login へ転送）。Next.js 16 で middleware.ts → proxy.ts に変わっている。9-08 の「middleware.ts は無い」は当時の事実。
- ★Claude の誤り2件（訂正済み）: ①「カルテに入力欄を置かないのが確定仕様」と答えたが、spec が決めていたのは置き場所だけで入力手段は未決だった ②nav の hidden を外す案を、隠した理由を測らずに出した（PR #59 の意図的な裏方化だった）。
- 既存の型番のパターンNO はほぼ全件空。入力は型番の編集画面から手で。先方支給のパターンは先方の番号を使うので一括投入しない。
- dev の絵型は WebP しか無い。PR-4 の dev 確認では透過 PNG とスマホ縦撮り JPEG を1枚ずつ足して見る。
- 絵型の読み出しは直列。枚数が多い品番で遅ければ Promise.all にする。
- ローカルに古い feature 枝が約49本残っている（害はない。消すなら remote に無いことを確かめてから）。
