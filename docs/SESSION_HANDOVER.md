## ④ ★構造の再定義 — 縫製仕様書は「下流の成果物」ではない

### 実務の現物（慎太郎さん 2026-08-10）

> 現在は、**縫製仕様書で付属や量産依頼をしています**。
> そのため、**サンプル製作ラウンドができれば縫製仕様書ができるはず**。
> 縫製指示が量産にしかないので、これをサンプルラウンドに入れてもらえれば、仕様書が完成する。
> そこに SKU も追加できれば、概ね量産と変わらないはず。

### 従前の（誤った）地図

```
[土台] SampleProduction に SKU ＋ 原価
   ┌──────┬──────────┬──────────┐
 納品書      縫製仕様書        インボイス
```

### 確定した地図（慎太郎さん承認済み 2026-08-10）

```
サンプル製作ラウンド
  ├─ 縫製指示（現在は量産にしかない → ラウンドに持たせる）
  ├─ SKU（色×サイズ）
  └─ 原価（発注から集計・量産と同じ経路）
        ↓ これらが揃うと
   縫製仕様書 = ラウンドの内容をそのまま出力したもの
        ↓
   納品書・インボイス・資材明細 は同じデータを別の形で出すだけ
```

**作るべきものは4つの別機能ではなく、1つの土台。**
サンプルラウンドを厚くすれば、縫製仕様書は「出力」として出てくる。
これは慎太郎さんの当初の直観「サンプル作成と量産作成があればいいだけ」に一致する。

### 慎太郎さんが挙げた必要事項（原文）

- サンプル製作ラウンドの**全て**が引き当ての候補に出る必要がある
- サンプル製作ラウンドに **SKU のテーブルとコストの明記**が必要
- 量産と同じように、**発注から原価計算した金額を合計して引き当て**、サイズ・カラーも加えて納品書を作成
- 納品書には **品番・先方品番・品名・サイズ・カラー・金額・備考**が明記される必要がある
- 以前のサンプルは**何サイズで何色を作ったかのログが残らない**
- 縫製仕様書は**色・サイズすべてテーブルに記入される**ため、情報として必ず必要
- 納品書・請求書も大事だが、**縫製仕様書・インボイス・輸出用の資材明細・HS コードも重要**
- 資材明細は**発注書と、仕入先から戻る生地企画書などから読み取って自動で書いてほしい**
