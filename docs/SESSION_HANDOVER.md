## ⑦ 原価計算の方向（2026-09-08 確認・メモ受信箱 M-003・c66a07c / 9a34297）

慎太郎さんの問い「材料合計を数量で割り返す方法をとってるけど、逆にする方がいいのでは」に対し、
spec 原文を検索して確認した結果、**過去に確定済み・変更不要**。詳細は M-003。

1. qe-1-spec-confirmation-v1_0-2026-06-30 §3-3（Q-a 確定）:
   1枚原価 =（材料費Σ + 工賃Σ）÷ Σ(productionQuantity)。分母は #93 資材所要量と揃える
2. ★**逆にできない構造的理由は同 §4。** ROLL（反売り）は 反数 = ceil(必要量 ÷ rollLength)、
   生地コスト = 反数 × rollPrice。**ceil があるため数量に対して非線形**で
   「1枚あたり × 枚数 = 総額」が成立しない（500枚3反・501枚4反）
3. ★工賃側も同型。qe-1-spec-addendum §3 で INDIVIDUAL_BILLING（版代・型代）は**総額固定**のため
   1枚原価の分子から外し別枠にすると確定済み。固定費は枚数で割るしかない
4. METER 行は線形なので積み上げでも一致するが、ROLL と混在するため全体は割り返しに揃える
5. ★「1枚単価から積み上げる」方式は **QE-1R（客向け提示）側で既に実装済み**
   （qe1r-road-a 実装ブリーフ §5-3「総額はすべて導出。電卓で合う」）＝**原価は割り返し・提示は積み上げの二層**

★未確認: src/lib/calc/production-cost.ts / material-requirement.ts の**現物は未読**。
実装が本当に ROLL の ceil を通しているかは着手時に read-only で確認する。
★別論点の可能性: 「数量が変わるたびに1枚原価が動くのが扱いにくい」「BOM 側に1枚あたりの単価を持ちたい」
であれば上の議論とは別。次に話す時に確認する。
