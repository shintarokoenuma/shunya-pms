- ★dev で useState の形を変えるコミットを積んだあと、ダイアログを開いたままの画面で「Cannot read properties of undefined」が出た。原因は Fast Refresh が古い state を保持したこと（コードの抜けではない・本番には無い）。**state の形を変えた後の確認は、ブラウザをフルリロード（Cmd + Shift + R）してから始める**（shunya-pr-url-checklist に追記を提案）。
- ★Claude の説明不足（1件・訂正済み）: D-45「サイズ表は画像」を確定したとき、「Excel のサイズ表のスクリーンショットを絵型に上げて選ぶ運用」だと伝えていなかった。慎太郎さんの「エクセルの表がマトリクスで入るよね？」で発覚。方針の「画像」「推奨」は、運用で誰が何をするかまで書いてから確認をとる。

- zsh の glob（`--include=*.tsx` は引用が要る）・Prisma の Factory は `factoryName`（`name` ではない）。
- dev の接続は時々切れる。read-only の確認はリトライでよい。
