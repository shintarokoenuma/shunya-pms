## ④ 本日の UI 診断（★次セッションの B-090 設計の前提になる）

### 確定した原因

- ★日本語フォントが未指定だった。Geist / Inter とも subsets:["latin"] で日本語グリフを持たず、
  日本語は全て OS フォールバック任せ。Windows では游ゴシック Regular に落ちて細く潰れていた。
  さらに --font-sans=Geist と body=Inter の二重指定、--font-mono が未定義の
  --font-geist-mono を参照していた。→ B-187 で解消（PR #138・ee69dcd）
- ★--border が oklch(0.922 0 0) で白に近すぎ、非Retina（Windows）でヘアラインが消えていた。
  → 0.88 に変更。B-119 に原因として追記済み
- ★文字サイズの階層が2段しかない。text-2xl(97) の見出しから、いきなり text-sm(589)・
  text-xs(432) の本文に落ちる。text-base(129) / text-lg(4) / text-xl(1) がほぼ未使用
- ★色の体系が無い。globals.css のトークンは --destructive（赤）以外すべて彩度ゼロ
  （oklch(x 0 0)）。ステータスの識別が濃淡だけに依存している → B-188 として起票
