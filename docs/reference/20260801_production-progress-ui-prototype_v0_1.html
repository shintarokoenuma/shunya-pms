    発注推奨

    品番品名引当可安全在庫 LT理由
    廃盤品には発注推奨を出しません。かわりに「取り置き量」の管理が必要になります。初回打合せの整理どおり追加オーダーが囲い込みの実体だとすると、廃盤生地を新規チームに先着で売り切るのは囲い込み資産の切り売りです。SYS-016「追加受注一覧_2021年から」からチームあたりの年間追加発生率を出せば、勘ではなく実績で取り置き量を決められます。

    ロット取り置き

    品番ロット残取置開放対象チーム
    追加オーダーの規約に「同じカラーのものをオーダーしても仕上がりの色合いが若干違って出来上がる」とありますが、これは生地ロットが変わると色が動くためです。初回と同ロットを取り置けば、この免責に頼らずに済みます。クレームと作り直しが減るので、在庫管理ではなく品質施策として位置づけています。

    進行管理が死ぬ理由は一つだけで、現場が入力しないことです。紙の発注書が30年続いているのは、現物と一緒に移動するので入力が要らないからです。置き換えるなら同じ性質が要ります。現物にQRを貼り、各工程で読むだけ。入力項目は「完了」と「数量」に絞る。写真やコメントは最初は載せないほうがいいと考えます。1タップより手数が増えた瞬間に更新されなくなり、システムが嘘をつき始めます。

    検品記録を残す理由

    検品基準が厳しすぎるのではないか、という論点がありました。いまは記録がないため、緩めるべきかどうかを判断する材料がありません。良品数・不良数・不良理由・処置を残せば、半年後には作り直しコストが数字で出ます。基準を変えるかどうかの議論はその後です。感覚で緩めると現場が納得しません。
