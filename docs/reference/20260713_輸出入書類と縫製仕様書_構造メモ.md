## 1. ベトナム無償輸出書類（SY 系・1ブック＝1出荷）

用途: ベトナム CMT 縫製（VIVAN GARMENTS VIET NAM）への材料無償輸出。
インボイス番号 = ファイル名 = ケースマーク（例 SY-5400508-VT-DD-01・番号中の4桁は
MMDD と推定）。「加工後に日本へ返送」「NO COMMERCIAL VALUE (VALUE FOR CUSTOMS
PURPOSE ONLY)」「COUNTRY OF ORIGIN : JAPAN」の定型文言＝免税（無償）輸出の要件表現。
バックログ「ベトナム免税輸出書類」の現物。

シート構成（確認した6本で同一の定型・全量に共通）:
| シート | 内容 |
|---|---|
| shipper master | 乙仲/フォワーダー提出用の項目マスター（S/CODE 連番＋項目名＋値。SHIPPER/BUYER/住所/TEL 等 約149行） |
| case mark | 箱マーク版下（インボイス番号・宛先・C/NO. 連番・MADE IN JAPAN を箱数分繰り返し） |
| invoice | 表紙。IMPORTER/CONSIGNEE・INVOICE NO/DATE・CONTRACT NO・PAYMENT（NO COMMERCIAL）・SHIPPED PER/FROM/TO・単位別合計行（M./PCS./SET.） |
| NARITA（(2) がある場合は追加分） | 明細 attached sheet ＝本体。下記列構造 |
| LABEL | 原産国ラベルシート（C/NO・ART NO・DESCRIPTION・原産国） |
| サンプル製品カタログ | 一部ブックのみ。サンプル現物の一覧 |

NARITA 明細の列構造（左＝書類面 / 右＝社内突合面の二重構造が最重要）:
- 書類面: C/NO. | ART NO.（生地品番等） | COLOR（C/#） | DESCRIPTION OF GOODS |
  Q'TY | 単位（M./PCS./SET.） | U/PRICE | AMOUNT
- 品目補足（行下に続く）: HS CODE・混率（例 acetate 100%）・組織/染め（例 朱子織
  後染めサテン）・WIDTH:122CM (135g/㎡)・長繊維/短繊維・テクスチャード加工の有無
  ＝関税分類に必要な記載一式
- 社内突合面（右側列）: 佐川伝票・明細 | 搬入日 | 伝票NO | 搬入内容 | 数量 | 箱数 |
  入庫NO ＝ 材料の入庫実績と書類明細の突合をこの Excel 内で人手運用している
- STYLE: 行（例 STYLE: 24A-PT01/02/03）で品番グルーピング

システム設計への示唆:
- 明細粒度は PoItem とほぼ同一（品番・色・数量・単価）＋ Material.hsCode /
  composition / fabricWidth が既に live schema に受け皿あり → 「PO 群から輸出書類
  一式（invoice/attached/label/case mark）を生成」が素直な将来機能（B-069 系・
  20260516_09_trade_documents.prisma が元設計）
- 右側の突合列は invoice×PO 突合バックログの現場運用の証拠。入庫実績
  （搬入日・入庫NO）との三点突合が要件になる
- TYOIR*.pdf はフォワーダー側帳票。Excel 書類群との対応関係の実例

## 2. 香港向け製品 INVOICE（INCREDIBLE・PDF 2本）

有償の製品販売側。原本は発行済み PDF（作業用 xlsx は名前を使い回して中身を更新する
運用のため、確定版は PDF）。2出荷分: 000-HK-01（2026-03-30・15個・¥480,000・
原産国 VIETNAM）／001-HK-01（2026-06-01・10個・¥320,000・原産国 JAPAN）。
BUYER=INCREDIBLE SHOP LIMITED（香港）・PAYMENT=T/T REMITTANCE 100% BEFORE・
F.O.B. TOKYO・銀行振込情報付き。
★設計要件: 原産国は案件ごとに可変（JAPAN/VIETNAM）— ベトナム CMT 製品の
第三国販売が実在するため、書類生成（B-069）は原産国を品番/出荷単位で持つこと。
シート: invoice（表紙）＋ invoice attach（明細: C/NO | ART NO | DESCRIPTION |
COLOR | サイズ展開（F/ONE/1/2/3）| Q'TY | U/PRICE | AMOUNT ＋ 混率/(WOVEN)/
(MADE IN JAPAN) の補足行）。
→ §1 の無償輸出と対になる「有償・製品」パターン。書類生成機能は無償/有償の
2態を最初からスコープに入れて設計すべき。

## 3. 縫製仕様書（INSONNIA PROJECTS M-65 パッチJKT）

シート構成: 縫製仕様書1（本体）／サイズ表(TOPS)／絵型／S仕様①〜⑦（縫製指示・
図形主体）。本体シートの構造:
- ヘッダ: ブランド・品名・パターンNO（16sy-082）・製品NO/仮品番・数量・納期・
  サンプル/量産区分・担当
- 裁断表: 仕入先（柴屋）× 色（カーキ/ブラック）× サイズ(1/2/3) 別の裁断枚数
- 附属マトリクス（最重要・色別に1ブロック）: 列＝表地/縫製糸/芯地/裏地/ドット釦/
  フロントファスナー/衿ファスナー/ウエスト・裾スピンドル/プリントパッチ生地/
  オリジナルプレート。各列に品番（例 YKK-7MGTH-OP-DADHR1・SIC A400F）・色番
  （C/#）・仕様（両端メタルチップ加工等）・数量/用尺
- 手配先行: 附属ごとの調達先（柴屋/ベトナム/エルミタージュ/ベトナムでプリント）
- 用尺単価行: 附属ごとの 用尺×単価 を横に積んで TTL（1枚あたり材料原価の積み上げ）
  ＝ QE-1 量産実績原価（PR #101・2026-07-15 本番リリース）の計算の現場 Excel 版が
  既に存在する証拠
- その他: ネーム位置・洗濯ネーム位置・柄合せ有無・生地方向（並/逆）等の縫製指示

システム設計への示唆:
- 附属マトリクス＝BomItem×colorway 構造そのもの（BOM 画面の現場対応物）
- 「色ごとに附属の色番が変わる」実例＝bom-item-colorways（調達カラー C/#）の妥当性確認
- サイズ表・S仕様ページは B-039（仕様書構造化・図形/採寸）・パターン管理
  （パターンNO 16sy-082 が実在の採番例）の一次資料

## 4. 生地企画書（柴屋・手書き PDF・AW1820/AW1821 の2枚）

印刷フォームに手書き記入で FAX/スキャン到着する形式。項目と読値（AW1820/1821 共通、
品番のみ相違）: 品名(和)=撚杢メランジ ネルチェック / 品名(英)=COTTON YARN DYED
HERRINGBONE / 混率=COTTON100% / 糸番手=30/2×30/2 / 打ち込み本数=68×44 /
生地幅×長さ=110/112cm×50m乱 / 目付=abt.185g/㎡ / 組織=綾織 / 染色方法=先染 /
生地の巻き=（空欄）。発行元=柴屋株式会社（大阪）・宛先=shunya。

システム設計への示唆:
- 項目が Material マスターの列とほぼ1対1（materialName/En・composition・
  fabricWidth・目付・rollLength・組織/染めは specification へ）→
  「手書き企画書の画像読解 → Material 登録ドラフト生成」が AI フェーズの具体ユースケース
- ★語彙「50m乱」: 「乱」＝反長が不定（約50m）の意。Material.rollLength を固定値と
  扱う ROLL 取り切り計算（QE-1 §4）に対し、実物は反ごとに長さが揺れる場合がある。
  将来の実務論点としてここに記録（v1 は名目値でよい）
