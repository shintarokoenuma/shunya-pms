## 1枚目の構造（文字の並びから読める範囲）

### ヘッダー（2段の格子）
- 1行目: 「○○ 御中」／表題「縫製仕様書」
- 2〜3行目: 「担当者：○○ 様」「気付：○○ 様分」
- 4行目: ブランド／品名／製品NO／型紙枚数／担当／数量／サンプル・量産
- 5行目: （ブランド名）／パターンNO／仮品番／（型紙枚数の値 例 22PT）／納期／職出し
- ★1項目に1行ではなく、**格子の中に横に詰めて並べる**。PDF のヘッダーを詰める参考になる
- PDF に無い項目: 気付、ブランド、品名、製品NO、仮品番、型紙枚数、数量（合計）

### 右上の欄
- 芯使用箇所（例: 前PKフラップ・後PKフラップ・見返し・持出し・ウエストベルト）／PM／G
- 生地品番・仕入先・裁断・サイズ
- ★**色（A〜D）× サイズ（S/M/L/XL）＋計** の数量表。色の行に生地の色名（例: A＝黒）が付く

### 縫製注意点（右側の縦の一覧）
- ネーム位置／洗濯ネーム位置／仕上げ方法／製品後加工／下げ札
- 縫製: ウエスト／前股ぐり／後股ぐり／脇／股下／裾（部位ごとの縫い方）
- 裏／糸／ステッチ／釦穴／柄合せ／さしこみ／生地方向
- ★システムの縫製指示11項目に近いが、**部位ごとの縫い方（ウエスト・股ぐり・脇・股下・裾）** は Excel にだけある

### 附属欄（★B-054 の付属の表の組み方に直結）
- ★**付属を横（列）に並べ、属性と色を縦（行）に持つ**。システムの BOM 表示（付属が行・色が列）と縦横が逆
- 列の例: 表地／芯地／別布／フロントスナップ／隠しスナップ／オープンファスナー／フロントファスナー／スレキ／STテープ／縫製糸／ステッチ糸／ピスネーム（1段に約12品）
- 行の例: 手配先（柴屋・YKK など）→ 色 A の行（黒: 品番 SB2030 / 色番 c/#5 など）→ 使用箇所（前当て布・前あき など）→ サイズ別の長さ（S:38c / M:39c …）→ 1着あたりの数（1セット・4セット・2本・0.5M）
- ★付属が多いと **「附属」の段を下に足していく**（シート内に「附属」の見出し行が複数ある）
- ★同じシートに **用尺・単価・一枚単価・1.1× などの原価の行** がある。PDF（工場に渡す帳票）には載せない

## 2枚目（サイズ表）
- 列: 1ST（指示寸）／2nd（指示寸）／S・M・L(マスター)・XL（それぞれ 指示寸・検寸）／ピッチ
- 行: ウエスト（ゴム上がり周囲・ゴムなし）／ベルト巾／股上前・後／股上／ヒップ／渡り／膝巾（最大・最小）／裾巾（最大・最小）／股下／ベルトループ巾・丈／ZIP 長さ
- ★仕様確認書 v1.0 D-8 の「縫い上がり寸と加工後の上がり寸の2列」とは別の組み方（指示寸と検寸・サンプル回ごとの列・ピッチ）。4b の設計時に突き合わせる
